# rain_fwtest — host harness for the rain decoder

Compiles `RainPng.cpp` (the firmware code, unchanged) against minimal
Arduino/FS stubs and decodes a RainViewer tile into a `.raw` frame
(240x240 indices into `kRainColors`, `rain_palette.h`).
`tests/rain/run.sh` uses it on the synthetic tiles of the fuzz corpus.

```bash
g++ -O2 -Dmemcpy_P=memcpy -I. -I../../tests/rain -I../../src/features/rain test.cpp ../../src/features/rain/RainPng.cpp -o fwtest
./fwtest tile.png out.raw 120            # 57,600-byte output
./fwtest tile.png out.raw 120 ring       # small-memory mode (2 KB ring + history)

g++ -O2 -Dmemcpy_P=memcpy -I. -I../../src/features/rain test2.cpp ../../src/features/rain/RainPng.cpp -o fwtest2x
./fwtest2x tile.png out.raw 120          # two decodes over one uncleared window: outputs must match
```

`test2.cpp` checks that no decoder state leaks from one decode into the next
(a static output state once kept its pixel count, so the second decode
failed) and that the LZ window's stale contents never reach the output.

Reference: `groundtruth.py` decodes the tile with zlib, premultiplies the
alpha on black, crops the centre KxK, upscales to 240x240 with the same 8.8
fixed-point bilinear filter (an exact replica of emitPair/emitRow) and
quantizes through the same lookup as the firmware (read from `rain_clut.h`,
generated by `tools/make_rain_palette.py`), then compares with the `.raw`
through `kRainColors`. Tiles in RainViewer's colour scheme (every real tile)
must match to the pixel.

```bash
python3 groundtruth.py tile.png out.raw 120
```

Test tiles: read `host` and a frame `path` from
`https://api.rainviewer.com/public/weather-maps.json`, then fetch
`{host}{path}/256/7/48.39/-4.49/2/1_1.png` (the JSON's host already
includes `https://`).
